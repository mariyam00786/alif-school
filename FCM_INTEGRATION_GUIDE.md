# FCM Integration Implementation Guide

## Overview

Firebase Cloud Messaging (FCM) has been fully integrated into both Flutter apps (student/teacher and admin) for push notification support. The implementation includes:

✅ Firebase Core & Messaging dependencies  
✅ FCM service with token management  
✅ Foreground & background message handling  
✅ Notification manager for UI integration  
✅ Test utilities for development  
✅ Complete setup documentation

## Quick Start

### 1. Generate Firebase Configuration

```bash
# Install FlutterFire CLI
dart pub global activate flutterfire_cli

# For student/teacher app
cd apps/alif_student_teacher
flutterfire configure --project=your-firebase-project-id

# For admin app
cd apps/alif_admin
flutterfire configure --project=your-firebase-project-id
```

### 2. Update Backend Environment

```bash
# Set Firebase credentials in services/api/.env
FIREBASE_PROJECT_ID=your-project-id
FIREBASE_CLIENT_EMAIL=your-email@your-project.iam.gserviceaccount.com
FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the App

FCM is automatically initialized on app startup. No additional setup needed!

## Usage Examples

### Get Current FCM Token

```dart
import 'package:alif_student_teacher/services/fcm_service.dart';

// Get token
String? token = FcmService.getToken();
print('My FCM Token: $token');
```

### Listen to Token Changes

```dart
FcmService.onTokenRefresh((newToken) {
  print('Token updated: $newToken');
  // Send new token to your backend
});
```

### Listen to Notifications in UI

```dart
import 'package:alif_student_teacher/models/notification_manager.dart';

// Build a stream-based UI
StreamBuilder<PushNotification>(
  stream: notificationManager.notifications,
  builder: (context, snapshot) {
    if (snapshot.hasData) {
      final notification = snapshot.data!;
      return Text('Notification: ${notification.title}');
    }
    return const SizedBox.shrink();
  },
)
```

### Get Notification History

```dart
// Get last 50 notifications
final history = notificationManager.getHistory(limit: 50);
for (var notification in history) {
  print('${notification.title}: ${notification.body}');
}
```

### Handle Notification Data

```dart
StreamBuilder<PushNotification>(
  stream: notificationManager.notifications,
  builder: (context, snapshot) {
    if (snapshot.hasData) {
      final notification = snapshot.data!;
      
      // Get specific data
      final screenName = notification.getData<String>('screen');
      final itemId = notification.getData<String>('item_id');
      
      // Navigate based on data
      if (screenName == 'leaderboard') {
        Navigator.pushNamed(context, '/leaderboard', arguments: itemId);
      }
    }
    return const SizedBox.shrink();
  },
)
```

### Request Permissions Explicitly

```dart
import 'package:firebase_messaging/firebase_messaging.dart';

final settings = await FcmService.requestPermission();
if (settings.authorizationStatus == AuthorizationStatus.granted) {
  print('Notifications enabled');
}
```

## Architecture

### FcmService

**Responsibilities:**
- Initialize Firebase
- Manage FCM token lifecycle
- Handle foreground messages
- Handle background messages (when app closed)
- Handle app opened from notification

**Key Methods:**
```dart
// Initialize FCM on app start
await FcmService.initialize()

// Get current token
String? token = FcmService.getToken()

// Refresh token
String? newToken = await FcmService.refreshToken()

// Listen to token changes
FcmService.onTokenRefresh((token) { ... })

// Delete token
await FcmService.deleteToken()
```

### NotificationManager

**Responsibilities:**
- Provide stream of notifications
- Store notification history
- Broadcast notifications to listeners

**Key Methods:**
```dart
// Access the global instance
notificationManager

// Listen to notifications
Stream<PushNotification> stream = notificationManager.notifications

// Get history
List<PushNotification> history = notificationManager.getHistory(limit: 50)

// Clear history
notificationManager.clearHistory()
```

## Message Handling States

| State | Handler | Behavior |
|-------|---------|----------|
| **App Open** | `FirebaseMessaging.onMessage` | Foreground listener called |
| **App Background** | `FirebaseMessaging.onMessageOpenedApp` | Called when user taps notification |
| **App Closed** | System notification + `FirebaseMessaging.onBackgroundMessage` | Firebase shows notification, app wakes up on tap |
| **App Starting** | `getInitialMessage()` | Check for notification that launched the app |

## Integration with Backend

### Store User FCM Token

To send personalized notifications, store user tokens on your backend:

```dart
// In user login/registration flow
String? token = FcmService.getToken();
if (token != null) {
  await ApiService.registerDeviceToken(token);
}

// Listen for token changes and update backend
FcmService.onTokenRefresh((newToken) {
  ApiService.updateDeviceToken(newToken);
});
```

### Send Notifications to Users

Create an API endpoint to send notifications:

```typescript
// Backend: services/api/src/routes/notifications.route.ts
router.post('/send-to-user/:userId', async (req, res) => {
  const { userId } = req.params;
  const { title, body, data } = req.body;
  
  // Get user's FCM tokens from database
  const tokens = await getUserTokens(userId);
  
  // Send to each token
  for (const token of tokens) {
    await messaging.send({
      token,
      notification: { title, body },
      data,
    });
  }
  
  res.json({ sent: tokens.length });
});
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| FCM token is null | Ensure Firebase is initialized, check internet connection |
| Notifications not showing on Android | Ensure notification channel is configured |
| Notifications not showing on iOS | Upload APNs certificate, test on physical device |
| "Firebase not initialized" error | Run `flutterfire configure` again |
| Background message not received | Check Firebase Console for quota limits |
| Token keeps changing | This is normal behavior, update backend each time |

## Security Considerations

1. **Never commit firebase_options.dart** to git with real credentials
2. **Validate tokens** on the backend before sending messages
3. **Use Firestore Security Rules** to restrict notification access
4. **Implement rate limiting** on notification endpoints
5. **Sanitize notification data** received from untrusted sources

## Performance Tips

1. **Debounce token updates** - don't update backend on every token change
2. **Compress notification data** - keep message size minimal
3. **Use notification channels** on Android for better organization
4. **Clear notification history** periodically to save memory
5. **Handle failed sends gracefully** - retry with exponential backoff
