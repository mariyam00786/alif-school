## Configuration Required

### Before First Run
1. **Generate Firebase Configuration:**
   ```bash
   flutterfire configure --project=your-firebase-project-id
   ```
   This creates the actual `firebase_options.dart` with real credentials

2. **Configure Backend:**
   ```bash
   # Set in services/api/.env
   FIREBASE_PROJECT_ID=...
   FIREBASE_CLIENT_EMAIL=...
   FIREBASE_PRIVATE_KEY=...
   ```

3. **Install Packages:**
   ```bash
   flutter pub get
   ```

## Known Limitations

- Test app requires FlutterFire CLI configuration before first run
- iOS push notifications require APNs certificate upload to Firebase Console
- Simulator doesn't support iOS push notifications (use physical device)
- Background message handling is limited by OS constraints (time limits)
